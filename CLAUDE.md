# JalanJer!

A Waze-style driving navigation app for Malaysia (Klang Valley first). iOS first, Android later.
Read `docs/PLAN.md` for features, the performance budget, the tech stack and milestones.
`IMAGE REFERENCES/` holds the Waze iOS screens we match. Expo-specific rules are in `AGENTS.md`.

## Hard constraints

- **Free only.** Open source and free tiers. Flag any cost explicitly; never make a paid service the default.
- **No Mac.** The owner develops on Windows. Never assume local Xcode or an iOS Simulator. iOS builds run on
  GitHub Actions macOS runners (`.github/workflows/ios-build.yml`); EAS Build free plan is the backup.
- **Smooth like Waze.** 60 fps floor on iPhone 11, 120 Hz on iPhone 15 Pro Max. No JS in the map gesture path;
  animations run on the UI thread (Reanimated worklets). Check the dev FPS overlay on device every milestone.
- **Git:** never add Claude/Anthropic/AI as co-author, and no "Generated with Claude Code" line in commits, PR
  titles/descriptions or comments. Commit as:
  ```bash
  git config user.name "syakir"
  git config user.email "169961481+sykrmzffr@users.noreply.github.com"
  ```
  (GitHub blocks pushes that expose the private email.)
- The owner is new to mobile tooling: write docs in plain language.

## Stack

Expo SDK 58 (React Native 0.88, New Architecture only) with dev builds (`expo-dev-client`, not Expo Go),
Expo Router (`src/app/`), MapLibre Native (`@maplibre/maplibre-react-native` v11), OpenFreeMap tiles,
Reanimated + Gesture Handler, MMKV, Zustand, FlashList, expo-image. UI chrome from beUI Native (Uniwind).

`ios/` and `android/` are generated by `expo prebuild` and gitignored. Change native settings in `app.json`
or config plugins, never in those folders.

## Layout

- `src/app/` routes (Expo Router). Keep non-route code out of it.
- `src/features/<feature>/` feature code (e.g. `features/map`).
- `src/theme/` design tokens: M3 color roles (light/dark), spacing, radius, typography, touch targets.
  `src/styles/theme.css` is **generated** from `src/theme/colors.ts` by `npm run tokens`.
- `src/components/`, `src/hooks/`, `src/primitives/`, `src/styles/motion.ts`: beUI Native source copied in
  by its CLI. Ours to edit, but keep edits small and commented so updates stay easy.
- `src/dev/` development-only tools (FPS overlay).

## Commands

```bash
npm start                    # Metro for the dev build (npx expo start --dev-client)
npx tsc --noEmit             # typecheck
npx expo lint                # lint
npx expo-doctor              # Expo config/dependency checks (needs reactnative.directory)
npm run tokens               # regenerate src/styles/theme.css after editing src/theme/colors.ts
npx expo install <pkg>       # add a dependency (picks SDK-compatible versions)
npx beui-native add <slug>   # add a beUI Native component (needs beui.dev)
npx expo export --platform ios   # bundle JS without a Mac (sanity check)
```

Run typecheck and lint before declaring work done. iOS builds: push and let the `iOS build` workflow run, or
start it from the Actions tab. Installing on the iPhone: `docs/IPHONE_INSTALL.md`.
Android `.apk` builds run on a free Linux runner (`.github/workflows/android-build.yml`); install guide:
`docs/ANDROID_INSTALL.md`.
