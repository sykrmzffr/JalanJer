# JalanJer!

A Waze-style driving navigation app for Malaysia. iOS first, Android later.

- Plan, features and performance budget: [`docs/PLAN.md`](docs/PLAN.md)
- Put the app on your iPhone from Windows: [`docs/IPHONE_INSTALL.md`](docs/IPHONE_INSTALL.md)
- Put the app on an Android phone: [`docs/ANDROID_INSTALL.md`](docs/ANDROID_INSTALL.md)

```bash
npm install
npx expo start --dev-client
```
